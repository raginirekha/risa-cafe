# RISA Café ☕

A simple and responsive café website created as a web development project.

## 🌐 Live Website

**RISA Café:**
https://raginirekha.github.io/risa-cafe/

## 📌 About the Project

RISA Café is a responsive café website designed to provide customers with a simple and attractive online café experience.

The website includes information about the café, menu items, contact details, shopping cart functionality, and an order/checkout section.

## ✨ Features

* 🏠 Home section
* ☕ Café menu
* 🥐 Croissants and desserts
* 🛒 Shopping cart
* ➕ Add items to cart
* 🔢 Quantity controls
* 📝 Order/checkout form
* 📍 Contact information
* 📱 Responsive design for mobile devices

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* GitHub Pages
